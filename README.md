# Earth Defense Lab

목성과 토성이 사라진 날, 운석이 지구로 쏟아지기 시작했다.
지구의 모든 영웅이 수단과 방법을 가리지 않고 운석을 막는다.

브라우저에서 돌아가는 지구 방어 게임의 **실험실 버전**입니다. 디아블로풍 마법 이펙트 실험에서 출발해, 지금 메인은 **요새 모드**예요. 세로 화면에서 지구 위 방어 플랫폼에 포탑을 달고, 30웨이브의 운석과 보스를 막는 로그라이크 디펜스입니다. 예전 게임은 **클래식 모드**(`classic.html`)로 그대로 남아 있어요.

![게임 화면](docs/screenshot.png)

## 실행

플레이만 할 때는 **https://sikrioo.github.io/earth-defense-lab/** 에서 바로 하면 돼요. `main`에 푸시하면 GitHub Actions가 자동으로 빌드해서 이 주소에 올립니다.

개발할 때 (Node 18 이상):

```sh
npm install
npm run dev            # 개발 서버, 저장하면 바로 반영
npm run build          # dist/ : 사이트용 빌드
npm run build:single   # dist-single/index.html : 이미지까지 전부 들어간 파일 하나 (오프라인용, 더블클릭으로 열림)
```

오프라인 파일 하나짜리는 Actions 실행 페이지의 `earth-defense-lab-offline` 아티팩트로도 받을 수 있어요. 외부에서 불러오는 건 Google Fonts뿐이고, 오프라인이면 기본 글꼴로 대신 그려집니다.

## 요새 모드 (메인)

- **진행:** 30웨이브. 보스는 10 거대 운석, 15 생체 행성, 20 떠돌이 행성, 25 생체 행성 + 거대 운석, 30 떠돌이 행성 + 생체 행성. 5웨이브와 13웨이브 이후 3의 배수 웨이브엔 수정 운석(엘리트)이 섞여요.
- **시점 3단계:** 1–10웨이브는 **전선**(지구 지평선 위, 위에서 내려오는 운석, 발판 6칸), 11–20웨이브는 카메라가 물러나며 **반구**(지구 절반, 위와 양옆에서 옴, 발판 8칸), 21–30웨이브는 **360°**(지구 전체가 가운데, 사방에서 옴, 발판 10칸). 시점이 넓어질 때마다 새 발판용 **새 포탑 카드**를 한 번 공짜로 골라요.
- **채굴:** 부서진 운석은 광물을 남겨요. 일반 광석(모든 운석), 결정 광석(철 운석·수정 운석·보스, 값어치 큼), 에너지 코어(엘리트·보스) 세 종류예요. 요새의 기본 일꾼 드론 2대는 느리고 적재량 3에 일반 광석만 나르고, **채굴기** 포탑의 드론은 빠르고 적재량 10에 전부 날라요. 방어막 가까이 떠다니는 광물은 자석이 끌어오고, 코어는 천천히 지구 쪽으로 떠내려와요. 광석은 12초(결정은 17초) 지나면 타서 사라지고, 드론은 운석에 부딪히면 4초간 격추돼요. 도감 `채굴` 탭에 드론·광물·코어 수치가 다 있어요.
- **에너지 코어:** 엘리트는 일반 코어(과충전 피해 +25% · 가속 속도 +20% · 확장 사거리/범위 +20%) 1개, 보스는 특이점 코어(피해 +40% · 속도 +15%)와 일반 코어를 떨궈요. 실어 오면 포탑의 **코어 슬롯**에 끼울지 고르거나 보관해요(일시정지 화면에서 나중에 끼우기). 슬롯은 처음 1개, 강화 4회에 2개, 8회에 3개. 한 번 끼우면 영구예요.
- **전투 리듬:** 운석은 한 방향에서 몇 개씩 묶여(일제 낙하) 오고, 3웨이브부터는 웨이브 중반에 경고와 함께 **METEOR SURGE**(웨이브의 1/4이 두 방향에서 한꺼번에)가 와요.
- **손맛과 위험 신호:** 맞은 운석은 뒤로 밀리고, 부서지면 파편이 튀어요. 엘리트·보스를 잡거나 보스가 방어막을 치면 아주 짧게 멈칫해요(히트스톱). 방어막에 닿기 직전인 운석 쪽 방어막이 붉게 빛나고, 맞은 자리에 금이 가요. 요새 체력이 30% 아래면 화면 가장자리가 심장박동처럼 뛰어요.
- **사운드:** 효과음은 전부 코드로 합성해요(파일 없음). 위쪽 `♪` 버튼이나 `M`으로 음소거, 브라우저가 기억해요.
- **카드 등장 비율:** 처음 두 번은 강화만 나오고, 그 뒤로 새 포탑 카드는 한 번에 최대 1장, 가끔씩 나와요(포탑이 많을수록 더 드묾). 시점이 넓어질 때는 새 포탑 카드를 따로 한 번 줘요.
- **에너지 → 카드:** 광석이 들어오면 에너지가 차고, 가득 차면 게임이 멈추고 카드 3장 중 하나를 골라요. 새 포탑, 포탑 강화, 요새 강화 중에서 나옵니다.
- **포탑 12종** (발판 6 → 8 → 10칸): 무기마다 분명한 단점이 있어서 조합이 중요해요.

  | 무기 | 강점 | 단점 |
  |---|---|---|
  | 개틀링 | 빠른 연사, 빠른 적도 맞춤 | 3초쯤 쏘면 과열, 장갑에 약함 |
  | 레이저 | 붙으면 최대 2.5배 | 전지 2.4초 쓰면 2.2초 충전 |
  | 미사일 | 유도 + 폭발 | 요새 가까운 적은 못 쏨(사각지대), 장전 느림 |
  | 냉각포 | 넓게 감속, 시너지 핵심 | 피해 아주 약함, 보스는 30%까지만 |
  | 테슬라 | 여럿에게 연쇄 | 사거리 짧음, 튈수록 -25% |
  | 리볼버 드론 | 위험한 적을 쫓아감 | 멈춰야 쏨 → 빠른 적을 놓침 |
  | 레일건 | 일직선 관통, 장갑 무시 | 충전 3.2초, 조준 고정 후 빗나감 |
  | 화염방사기 | 부채꼴 화상, 생체형 +60% | 사거리 아주 짧음, 장갑에 거의 안 먹힘 |
  | 인터셉터 모함 | 요격기가 화면 어디든 날아가 쏨 (360°에 강함) | 탄창을 비우면 돌아와 재장전, 한 발이 약함 |
  | 플락포 | 공중에서 터져 파편으로 떼를 정리 | 파편이 약해 장갑에 막힘, 멀면 조준이 흔들림 |
  | 채굴기 | 광석·코어를 빠르게 실어 옴 | 공격 안 함(발판 하나만큼 화력 손해), 드론 격추 |
  | 스톰 발생기 | 몰린 곳에 번개 폭풍(지속 피해) | 재사용 4초, 펼쳐지기까지 0.6초, 겹쳐도 안 쌓임 |

  각 무기 카드에는 단점이 같이 적혀 있고, 단점을 줄이는 강화 카드(냉각 재킷, 대용량 전지, 근접 신관, 자이로 안정, 추적 조준, 확장 탄창, 철갑 파편, 유도 폭풍 등)도 있어요. 탄두 수를 늘리는 건 미사일 `다연장`(+2발, 최대 3번), 레이저 지속 시간은 `대용량 전지`(+40%, 최대 3번)와 `급속 충전`이에요.
- **도감:** 위쪽 `도감` 버튼(또는 `C`, 일시정지 화면)으로 열어요. 무기 탭은 강점·단점·기본 수치·강화 카드 전부, 적 탭은 만난 적의 특징과 수치를 보여줘요. 아직 못 만난 적은 실루엣과 `???`로 나오고, 처음 만나면 "도감 등록"이 떠요(브라우저에 기억).
- **시너지:** 냉각포 `파쇄`는 냉각된 운석이 받는 모든 피해를 올려요. 레이저 `융해`와 테슬라 `도체`도 냉각된 운석에 추가 피해예요.
- **적:** 운석, 파편 떼(지그재그), 분열 운석(파편 3개로 쪼개짐), 철 운석(장갑), 붉은 혜성(궤적 경고 뒤 고속 돌진, 큰 피해), 수정 운석(엘리트). 8웨이브부터는 생체형 포자(꿈틀대며 다가옴)와 기생 포드(터지면 포자 3개)도 나와요. 보스는 3종이에요.
- **난이도:** 테스트 봇 기준으로, 집중해서 고르는 봇은 대개 13~19웨이브(반구 시점에서 고비), 무작위로 고르는 봇은 10~13웨이브에서 무너져요 (`?auto=smart` / `?auto=1`).
- **조작:** 손댈 것 없이 포탑이 알아서 쏴요. 카드 고르기(탭 또는 `1` `2` `3`), `×1/×2` 속도(스페이스), 일시정지(`P` / `Esc`)만 있어요.
- **숫자:** 전부 `src/td/data.js`에 있어요 (운석 스탯, 웨이브 곡선, 포탑 기본값, 카드 효과, 에너지 곡선).
- **스테이지 선택 (테스트용):** 일시정지 화면 아래 `테스트 · 스테이지 선택`에서 시작 웨이브(1–30), 시점(자동/전선/반구/360°), 건너뛴 웨이브의 카드(자동 선택/직접 고르기/받지 않기)를 정하고 바로 시작할 수 있어요.
- **테스트용 주소 옵션:** `?auto=1`은 카드 무작위 자동 선택, `?auto=smart`는 집중 빌드 봇, `?speed=4`는 4배속, `?wave=12`는 12웨이브부터 시작, `?view=full`은 시점 고정(`line`/`half`/`full`)이에요. 예: `index.html?auto=1&speed=6`으로 밸런스를 빠르게 돌려볼 수 있어요.

## 클래식 모드 (classic.html) 조작

| 입력 | 동작 |
|---|---|
| 클릭 / 길게 누르기 | 선택한 스킬 시전 (마나 소모) |
| `S` | 스킬 고르기 |
| `1`–`0` | 스킬 선택 |
| `Q` `W` `E` `R` `T` `Y` | 클래스 전환 (소서리스 · 아마존 · 팔라딘 · 네크로맨서 · 바바리안 · 현상금 사냥꾼) |
| 슬롯 카드 | 슬롯 정보 · 변경 · 강화 |
| `BAG` | 가방 (장비 · 재료) |
| 레벨업 카드 | 클릭 또는 `1` `2` `3` |

오른쪽 위 버튼: 그래픽(에셋/코드), 맵(지구 방어선/궤도 방어), **MAX 시뮬**, 처음부터.

## 클래식 모드에 들어가 있는 것

**리볼버 링 (주 무기, 완전 자동)**
- 6연발 실린더 모양 조준경이 지구에 가장 가까운 운석부터 쫓아가 일정 간격으로 범위 안을 전부 타격
- 연속 명중 시 스타일 랭크 상승: D DRY → C COOL → B BLUE → A ACE → S SWING → SS BEBOP (랭크당 피해 +10%)
- 레벨업마다 카드 3장 중 하나 선택: 링 추가(최대 8개), 화력, 연사, 구경, 기동, 특수능력(냉각탄 · 도탄 · 폭발탄 · 견인)

**자전하는 지구**
- 실제 경도에 배치된 도시 12개가 자전에 따라 이동
- 도시에 떨어지면 지구 피해 2배, 도시마다 방어 3칸, 다 깎이면 함락

**운석 종류**
- 일반 · 러너 · 브루트 · 유성 · 엘리트 · 보스
- 붉은 혜성: 아주 빠르게 직선 비행, 절반은 지구로 오고 절반은 스쳐 지나감
- 분열 운석: 부수면 파편 3개로 쪼개짐
- 유성우 (이벤트): 작은 돌 14개가 한꺼번에 비스듬히 쏟아짐
- 떠돌이 행성 (이벤트): 거대하고 느림, 전용 체력바, 충돌 시 큰 피해

**파밍 (디아블로식)**
- 코어(자동 공격)와 부적(옵션)을 슬롯 6칸에 장착, 슬롯은 레벨 1·3·6·10·15·20에 열림
- 장비는 엘리트·보스·떠돌이 행성에서만 드랍, 재료(운석 파편 · 별금속 · 항성 핵)로 +10까지 강화

**스킬 클래스 6종**: 소서리스, 아마존, 팔라딘, 네크로맨서, 바바리안, 현상금 사냥꾼 (스킬 수치는 `docs/bounty_hunter_skills.xlsx` 참고)

**MAX 시뮬**: 운석 4배 + 모든 강화 최대 + 지구 무적. 최종 단계 밸런스와 성능 확인용.

**기능 넣고 빼기 예시**
- 새 운석: `data/enemy-types.js`에 한 줄 + 필요하면 `enemies/painters.js`에 그리는 함수
- 스킬 클래스 빼기: `skills/index.js`의 `CLASSES`에서 그 항목을 지우면 탭과 단축키에서 사라짐
- 링 밸런스: `data/rings.js`의 숫자만 수정

**테스트**

```sh
pip install playwright && python3 -m playwright install chromium   # 처음 한 번
npm run build && npm run smoke
```

**그림 다시 굽기** — `tools/` 안에서 지구 텍스처를 먼저 받아야 해요 (`three-globe` npm 패키지의 예제 이미지 사용):

```sh
cd tools && mkdir -p dl_globe && cd dl_globe && npm pack three-globe@2.45.6 && tar xzf three-globe-*.tgz && cd ..
python3 render_cel.py rocks    # earth | debris | test
```

결과는 `tools/out_cel/`에 생겨요. 지금 베이커는 예전 한 파일 방식대로 데이터 URI를 JSON으로 내놓기 때문에, 새 그림을 넣으려면 그 안의 webp를 `assets/`의 같은 이름 파일로 바꿔 넣으면 됩니다.
